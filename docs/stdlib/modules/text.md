## Overview

> **Overview vs Reference:** This section is curated prose — it explains when and how to use this module family. The sections below are exhaustive generated reference tables sourced directly from `std/manifest.toml` and source doc comments.

The `std::text` module extends the prelude's built-in string type with inspection, trimming, searching, transformation, padding, and primitive formatting helpers. If you need to check whether a string is empty, split it into lines, remove whitespace, or format a number, start here.

**Recommended API highlights:**

| API | Purpose |
|-----|---------|
| `trim(s)` / `trim_start(s)` / `trim_end(s)` | Strip ASCII whitespace from both, leading, or trailing end. |
| `replace(s, from, to)` | Replace all non-overlapping occurrences of `from` with `to`. |
| `lines(s)` | Split a string on newlines into a `Vec<String>`. |
| `index_of(s, needle)` | First byte index of `needle`, or -1 when not found. |
| `format_i32(n)` / `format_f64(n)` | Format numeric values as decimal strings. |
| `pad_left(s, width, fill)` / `pad_right(s, width, fill)` | Fixed-width string padding. |

**Target constraints:** Target availability: `wasm32` and `wasm32-gc`. Host dependency: no. Explicit runtime permission: none beyond providing the documented host profile.

**Typical usage:**

> ⚠️ **Eradication scope (ADR-046):** the free helpers below remain callable but are scheduled for removal as method / associated equivalents land — [scorecard](../eradication.md) (issue #917).

```ark
import std::text

let s = "  hello, world!  "
let trimmed = trim(s)              // "hello, world!"
let parts   = lines("a\nb\nc")   // ["a", "b", "c"]
let idx     = index_of(s, "world")  // 9
let label   = pad_right(format_i32(42), 6, " ")  // "42    "
```

## Module `std::text`

String helpers for the text APIs.

The free `std::text` functions were retired by #917 in favor of receiver
methods on `String` (`s.trim()`, `s.split(sep)`, `s.len_chars()`, …) and
the associated `String::from_utf8_lossy` / `String::try_from_utf8`
constructors. `Vec<String>::join` replaces `std::text::join`, the empty
string literal replaces the old builder constructors, and
`std::text::fmt::DebugFormat` owns the container `Debug` renderings that
cannot yet dispatch through a generic `impl Debug for Vec<T>`.

Importing `std::text` registers the `impl String` and `impl Vec<String>`
blocks from `std::collections::string`; the module itself exposes no free
functions (ADR-046).

Byte-oriented and Unicode-scalar operations use separate index domains:
`byte_at`, `len_bytes`, and `slice_bytes` use byte indices, while
`len_chars`, `codepoint_at`, `chars`, and `slice_chars` use scalar indices.
The module does not define grapheme-cluster segmentation or normalization.
