## Overview

> **Overview vs Reference:** This section is curated prose — it explains when and how to use this module family. The sections below are exhaustive generated reference tables sourced directly from `std/manifest.toml` and source doc comments.

The `std::core` family provides the fundamental building blocks shared across the standard library: integer ranges (`Range`, `RangeInclusive`), the shared `Error` type used by fallible stdlib operations, the provisional static-dispatch `std::error::Error` trait, and low-level hash utilities used internally by collection modules. Import only the sub-module you need — most application code uses only `std::core` (ranges) and the `Error` type from `std::core::error`; application error payloads use `std::error`.

**Recommended API highlights:**

| API | Purpose |
|-----|---------|
| `Range::new(start, end)` | Create a half-open range `[start, end)`. |
| `r.contains(value)` | Test membership in a range. |
| `r.len()` | Length of a half-open range. |
| `e.message()` | Convert a stdlib `Error` variant to a human-readable string. |
| `Error::source()` | Expose a rendered immediate cause through static dispatch. |
| `value.hash()` | Hash a value through its registered `Hash` trait impl. |

**Target constraints:** Target availability: `wasm32` and `wasm32-gc`. Host dependency: no. Explicit runtime permission: none beyond providing the documented host profile.

**Typical usage:**

```ark
use std::core::{Range}
use std::host::stdio

let r = Range::new(0, 10)
if r.contains(5) {
    stdio::println("5 is in range")
}
let len = r.len()  // 10
```

**Availability:** All targets (`wasm32` + `wasm32-gc`). No host capability required.

### no-sentinel-i32 rule

New public stdlib APIs MUST NOT return a raw `i32` value of `-1` (i.e.
`0 - 1`) to signal absence or failure.  Use the preferred surface instead:

- absence / EOF → `Option<T>` with `None`
- distinguishable failures → `Result<T, Error>` using the variants below

Existing `-1`-returning functions are kept only as backward-compatible
adapters.  When adding new APIs, always provide a `try_*` / `Option`-first
variant and document the legacy form as deprecated.

## Module `std::core::hash`

Small hashing helpers used by the current collection implementations.

Provides the `Hash` trait and built-in implementations for `i32`, `i64`,
`String`, `bool`, `char`, and `f64`, plus the `combine` helper. The
canonical dispatch surface is the receiver method `value.hash()`.

**Hash policy:** All integer and string hashing uses a consistent FNV-1
algorithm (offset_basis=216613626, prime=16777619) applied byte-by-byte
over the key representation.  This avoids policy drift between key types
and provides reasonable distribution for hash table operations.

**Availability:** All targets (`wasm32` + `wasm32-gc`). No host capability required.

Static error protocol for the standard library.

`Error` is separate from the legacy `std::core::error::Error` enum so the
existing stable enum and its constructors remain source-compatible. The
protocol is provisional while typed source objects and a dynamic error ABI
remain outside the static-dispatch language contract.
