## Overview

> **Overview vs Reference:** This section is curated prose — it explains when and how to use this module family. The sections below are exhaustive generated reference tables sourced directly from `std/manifest.toml` and source doc comments.

The `std::seq` module provides eager sequence helpers over `Vec<i32>`: search, aggregation, deduplication, and reversal. Lazy pipelines and closure-heavy adapters are deferred to a future release.

**Recommended API highlights:**

| API | Purpose |
|-----|---------|
| `binary_search(vec, value)` | Binary search a sorted vector; returns index or -1. |
| `min_i32(vec)` / `max_i32(vec)` | Find the minimum or maximum element. |
| `sum_i32(vec)` | Sum all elements in a vector. |
| `unique(vec)` | Remove duplicates, preserving first occurrence. |
| `seq_reverse(vec)` | Return a reversed copy of the vector. |
| `seq_contains(vec, value)` | Linear search for membership. |

**Target constraints:** Target availability: `wasm32` and `wasm32-gc`. Host dependency: no. Explicit runtime permission: none beyond providing the documented host profile.

**Typical usage:**

```ark
import std::seq

let nums = vec![3, 1, 4, 1, 5, 9]
let total = sum_i32(nums)           // 23
let lo    = min_i32(nums)           // 1
let dedup = unique(nums)            // [3, 1, 4, 5, 9]
```
